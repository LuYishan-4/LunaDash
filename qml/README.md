# LunaDash Shell

This directory contains LunaDash's Quickshell/QML desktop interface. The root LunaDash repository also provides its C++ desktop services, translations, assets, and installed Quickshell runtime.

QML changes are committed in the root LunaDash repository with any related host, translation, asset or documentation changes. Validate them with the QML design/action audits and Qt/Wayland workflows.
